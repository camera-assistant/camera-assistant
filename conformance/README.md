# Conformance kit

This folder is for the conformance kit. It proves that a detection module does what the detection contract says, on the hardware it claims.

- `cases/`: the reference cases. Each one is a short clip, its licence and the detections it must produce.
- `runner/`: `ca-conformance`, which runs a module against the cases and reports the result.

Reference clips must be free to share, and recorded with the consent of anyone who can be recognised in them.
